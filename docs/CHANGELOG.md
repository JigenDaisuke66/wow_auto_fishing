# 修改记录

## 2.0.0 - 2026-08-13

- 将原 542 行单文件拆分为入口、配置、文案、界面、视觉和工作线程模块。
- 修复配置加载发生在界面控件创建前的问题。
- 修复防挂机首次搜索时立即触发、每轮重新随机判断的问题。
- 防挂机现在预先生成下一触发时刻，并在每次执行后重新调度。
- 删除不安全的 `QThread.terminate()`，改用协作式中断和可中断等待。
- 模板图片改为启动时缓存，不再在每次搜索时读取磁盘。
- 模板匹配由全屏缩小为游戏客户区，并在多个模板中选择最高置信度结果。
- 支持中文图片路径。
- 咬钩检测升级为基线差异、变化像素比例及连续帧联合确认。
- 将游戏窗口标题放入独立的“游戏窗口”标签页，保持可修改。
- 界面固定文案集中管理，默认显示简体中文。
- 更新界面布局和视觉样式。
- 增加运行依赖与项目文档。
- 增加简体中文与英文界面选项，切换后立即生效并保存选择。
- 工作线程日志及错误提示会跟随界面语言。

## 历史版本

- 1.x：单文件 PyQt5 界面、全屏模板匹配、相邻帧平均差检测。
