# 魔兽钓鱼助手

这是一个仅供图像识别和桌面自动化学习参考的 Windows 项目。任何自动输入行为均可能违反游戏服务条款并导致封号，使用后果由使用者承担。

程序使用 OpenCV 在游戏窗口内定位浮漂，并通过“平均图像差异 + 变化像素比例 + 连续帧确认”判断咬钩。

## 使用方法

1. 使用任意截图软件截取浮漂叶子图像。尽量只保留有辨识度的区域，可准备不同光照、角度下的多张模板。

2. 点击“添加图片”选择模板。新版支持中文文件名和路径。

3. 设置钓鱼快捷键，并在“游戏窗口”标签页确认窗口标题。默认值为“魔兽世界”，可以修改。

4. 点击“开始运行”，观察程序能否找到浮漂并在咬钩时右键收杆。

5. 无法识别时可降低模板匹配置信度；出现错误匹配时提高置信度。

6. 误收杆时提高平均差异、变化像素比例或连续确认帧数；一直不收杆时优先降低平均差异阈值。运行日志会同时显示三项判断数据。

## 源码运行

```powershell
py -3 -m pip install -r requirements.txt
py -3 auto_fishing.py
```
